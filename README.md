# 飞牛NAS Docsify 文档库
欢迎使用飞牛NAS部署的Docsify文档站点！

## 简介
本站点基于Docsify搭建，用于存储、管理各类文档（如NAS使用教程、网络配置笔记、家庭文件说明等），支持实时编辑、自动搜索、多级导航。

## 快速操作
1. 编辑文档：直接在飞牛NAS文件管理器中，修改 `docs` 目录下的 `.md` 文件
2. 新增文档：在 `docs` 目录新建 `.md` 文件，然后在 `_sidebar.md` 中添加导航
3. 刷新生效：修改文档后，刷新浏览器即可看到最新内容

## 访问地址
内网访问：http://你的NAS_IP:3000
外网访问：可搭配CF Tunnel、EasyTier等内网穿透工具实现
